# Fit Girl Things

Editorial wellness collective — [fitgirlthings.com](https://fitgirlthings.com).

Astro + React islands + Decap CMS. Deploys to Netlify from `main`.

## Quick start

```bash
npm install
npm run dev          # dev server @ http://localhost:4321
npm run build        # production build to /dist (also builds Pagefind index)
npm run preview      # serve /dist locally
npm run qa           # Playwright QA suite (routes / nav / forms / SEO / theme)
npm run qa:ui        # QA with the Playwright UI
npm run qa:install   # first-time only — install Chromium
```

## Publish new content

The site has two content types, each authorable in `/admin` (Decap CMS)
**or** via the CLI scaffolders below.

```bash
npm run new:article "how-to-recover-like-a-pilates-princess" --category=Wellness
npm run new:landing "black-friday-newsletter" --template=high-ticket
```

Each command drops a stub file with a `TODO`-marked frontmatter, opens
in your editor, and ships automatically on the next Netlify deploy.

Article + event scaffolds default to `draft: true` — flip to `false` when
ready to publish.

## Landing Page Builder

Landing pages compose from a block library at `src/components/landing-blocks/`:

| Block | Purpose |
| --- | --- |
| `Hero` | Punchy value prop + primary/secondary CTA + optional image |
| `PAS` | Problem / Agitation / Solution — direct-response framework |
| `SocialProof` | Stats bar + testimonial quotes |
| `LogoStrip` | Client / partner logo row |
| `FeatureTriad` | Three-column benefit grid |
| `PriceAnchor` | Tiered pricing with a highlighted anchor tier |
| `FAQ` | Objection handling with accordion |
| `Guarantee` | Risk-reversal with badge |
| `Urgency` | Deadline / scarcity bar |
| `CloseCTA` | Final call with reassurance line |
| `Testimonials` | Editorial-serif quote grid |
| `VideoEmbed` | YouTube / Vimeo embed |

Pages live at `src/content/landing/<slug>.json` and render at `/for/<slug>`.
See [`src/content/landing/newsletter.json`](src/content/landing/newsletter.json)
for a full example.

Compose in Decap CMS at [/admin](/admin) — the block picker lists every type.

## Directory layout

```
src/
├── content/                 # Content collections (articles, landing)
│   ├── articles/            # MDX articles — category = URL prefix
│   └── landing/             # Block-composed /for/<slug> pages
├── components/
│   ├── ui/                  # Primitives
│   ├── nav/                 # Topbar, Footer
│   ├── home/                # Home page sections
│   ├── landing-blocks/      # Landing page block library + Renderer
│   └── react/               # Interactive islands (NewsletterForm)
├── layouts/                 # BaseLayout, ArticleLayout, LegalLayout
├── pages/                   # File-based routes
│   ├── index.astro          # Home (magazine mix of latest articles)
│   ├── [category]/          # /spotted, /fit-girl-news, /wellness,
│   │   ├── index.astro      #   /fitgirlfind, /fit-girls — category index
│   │   └── [slug].astro     #   + article detail pages
│   ├── faqs.astro           # /faqs
│   ├── for/[campaign].astro # /for/<slug> landing pages
│   └── (legal pages)        # /privacy, /terms, /cookies, /disclaimer, /contact
├── styles/                  # Tokens + global CSS
├── lib/                     # Site config, category taxonomy, utilities
└── data/                    # Home hero JSON (Decap-editable)
scripts/                     # new-landing, new-article, new-event scaffolders
tests/                       # Playwright QA (routes, nav, forms, SEO, theme)
public/
├── admin/                   # Decap CMS
└── uploads/                 # CMS-uploaded + migrated media
```

Article URLs mirror the site's original category structure
(`/spotted/…`, `/fit-girl-news/…`, `/wellness/…`, `/fitgirlfind/…`,
`/fit-girls/…`) via the `categories` taxonomy in `src/lib/site.ts`.

## Newsletter form

Forms POST to **Netlify Forms**. Nothing to configure — Netlify auto-detects
the hidden static forms in `BaseLayout.astro` at deploy time, and submissions
land in the Netlify dashboard.

To swap to SendFox (or another provider), edit the `fetch()` URL in
`src/components/react/NewsletterForm.jsx` (currently posts to `/`) and add the
provider's endpoint + auth headers. All other form logic stays.

## Analytics

**Server-side Netlify Analytics** works out of the box — enable in the
Netlify project dashboard. No key needed.

To add **Plausible**, uncomment the script tag near the bottom of
[`src/layouts/BaseLayout.astro`](src/layouts/BaseLayout.astro) and set
`data-domain`.

## Dark mode

Toggle in the top nav. Persists per-visitor in `localStorage`. Respects
`prefers-color-scheme` when unset.

## SEO

Every page emits:
- Canonical URL, OG tags, Twitter Card meta
- Organization JSON-LD site-wide
- Article JSON-LD + BreadcrumbList on every `/[category]/[slug]` page
- FAQPage JSON-LD on `/faqs`
- `sitemap-index.xml` auto-generated by `@astrojs/sitemap`
- `robots.txt` served from `public/`

## QA before shipping

```bash
npm run build   # must succeed with zero errors
npm run qa      # every route, every nav link, every form, SEO meta, theme toggle
```

CI (Netlify) runs `npm run build` on every push; Playwright is run locally or in a separate CI you can wire up.
